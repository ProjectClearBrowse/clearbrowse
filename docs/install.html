インストール手順

パソコン版の Chrome / Edge / Brave に、zip ファイルから手動で追加する方法です。所要時間は約3分です。バージョン 2.0.0

ストアを通さずに追加する方法をご案内いたします。パソコンの操作に不慣れな方でも進めていただけるよう、押すボタンの名前を、そのまま記載しております。

  1. zip ファイルをダウンロードします

    下のボタンを押してください。「ダウンロード」フォルダに、clearbrowse-extension.zip という名前で保存されます。

    zip ファイルをダウンロード(v2.0.0)

    ブラウザに「このファイルは危険です」といった警告が表示された場合は、本サイトから入手したファイルであることをご確認のうえ、「保存」を選択してください。

  2. zip ファイルを展開し、削除しない場所に置きます

    Windows の場合: ダウンロードした zip ファイルを右クリックし、「すべて展開」から「展開」を押してください。展開されたフォルダが開きます。

    Mac の場合: zip ファイルをダブルクリックすると、フォルダに展開されます。

    できあがったフォルダは、「ドキュメント」フォルダなどに移動してください。

    このフォルダは、拡張機能をお使いの間、削除や移動をしないでください。削除すると、拡張機能が動作しなくなります。

    フォルダを開き、manifest(種類: JSON ファイル)や popup、content などのファイルが直接並んでいれば、正しい場所です。

  3. 拡張機能の管理画面を開きます

    ブラウザの一番上にあるアドレスバー(https:// と表示されている欄)をクリックし、次の文字を貼り付けて、Enter キーを押してください。

    chrome://extensions

    Edge の場合は、次の文字を貼り付けてください。

    edge://extensions

    ブラウザの安全のため、このアドレスは、ウェブページのリンクから開くことができません。お手数ですが、コピーして貼り付けてください。

  4. 「デベロッパー モード」をオンにします

    管理画面の右上にある「デベロッパー モード」のスイッチを押し、オン(青色)にしてください。

    Edge の場合は、画面の左側のメニューにある「開発者モード」をオンにしてください。

  5. 「パッケージ化されていない拡張機能を読み込む」を押します

    デベロッパー モードをオンにすると、画面の左上に、このボタンが表示されます。押してください。Edge の場合は、「展開して読み込み」というボタンでございます。

    フォルダを選択する画面が開きますので、手順2で置いたフォルダを選び、「フォルダーの選択」を押してください。手順2の最後にご確認いただいた、ファイルが直接並んでいるフォルダを選択してください。

  6. ピン留めをして完了です

    一覧に「クリアブラウズ」が表示され、スイッチがオン(青色)になっていれば、追加は完了です。

    ブラウザ右上のパズルの形のボタンを押し、クリアブラウズの横にあるピンのマークを押すと、ツールバーにアイコンが表示されます。

    広告のあるサイトを開いて、お試しください。

うまくいかない場合

「マニフェスト ファイルが見つからないか、読み取れません」と表示される選択したフォルダの場所が、ずれている可能性がございます。manifest のファイルが直接入っているフォルダを、選び直してください。フォルダの中に、同じ名前のフォルダがもう一つある場合は、その中のフォルダでございます。
「パッケージ化されていない拡張機能を読み込む」が見当たらない「デベロッパー モード」がオフになっております。手順4をご確認ください。
ブラウザの起動時に、デベロッパー モードの拡張機能に関する警告が表示されるストアを通さずに追加した拡張機能では、表示されることがございます。画面を閉じてください。「無効にする」を押すと、拡張機能が停止しますので、ご注意ください。ストアで公開された後は、ストア版に入れ替えていただくことで、表示されなくなります。
追加したのに、アイコンが見当たらない手順6のピン留めを行ってください。
広告が消えない広告のあるページを、再読み込みしてください。YouTube など、動画の中に広告が組み込まれているサイトでは、ブロックできない場合がございます。それ以外のサイトで広告が残る場合は、サポートページに記載の方法で、お知らせください。
拡張機能の欄に、赤色の「エラー」ボタンが表示されている押すと、エラーの内容をご確認いただけます。画面を撮影のうえ、サポートページに記載の方法で、お知らせください。

新しい版に更新する場合

  1. 新しい zip ファイルをダウンロードし、展開します

    手順1と手順2と同様に行ってください。

  2. 古いフォルダの中身を、新しいファイルで置き換えます

    同じ名前のファイルは、上書きしてください。

  3. 管理画面で「更新」を押します

    管理画面で、クリアブラウズの欄にある、丸い矢印のボタンを押してください。その後、広告のあるページを再読み込みします。

削除する場合

管理画面で、クリアブラウズの欄にある「削除」を押してください。設定やエラーログも、すべて削除されます。その後、展開したフォルダも削除していただいて問題ございません。
