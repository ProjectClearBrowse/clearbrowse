インストール手順

パソコン版の Chrome / Edge / Brave で、zip から手動で追加する方法です。所要時間は約3分。バージョン 2.0.0

ストアを通さずに追加する方法です。パソコンに慣れていない方でも進められるよう、押すボタンの名前を、そのまま書いてあります。

  1. zip をダウンロードする

    下のボタンを押します。「ダウンロード」フォルダに、clearbrowse-extension.zip という名前で保存されます。

    zip をダウンロード(v2.0.0)

    ブラウザに「このファイルは危険です」などの表示が出たときは、ファイルの出どころがこのサイトであることを確認して、「保存」を選んでください。

  2. zip を展開して、消えない場所に置く

    Windows: ダウンロードした zip を右クリックして、「すべて展開」→「展開」を押します。展開されたフォルダが開きます。

    Mac: zip をダブルクリックすると、フォルダに展開されます。

    できたフォルダを、「ドキュメント」フォルダなどに移動してください。

    このフォルダは、拡張機能を使っている間、削除も移動もしないでください。消すと、拡張機能が動かなくなります。

    フォルダを開いて、manifest(種類: JSON ファイル)や popup、content などのファイルが、直接並んでいれば正しい場所です。

  3. 拡張機能の管理画面を開く

    ブラウザの一番上にあるアドレスバー(https:// と書いてある欄)をクリックして、次の文字を貼り付けて、Enter キーを押します。

    chrome://extensions

    Edge の場合は、こちらです。

    edge://extensions

    ブラウザの安全のため、このアドレスは、ウェブページのリンクからは開けません。コピーして貼り付けてください。

  4. 「デベロッパー モード」をオンにする

    管理画面の右上にある「デベロッパー モード」のスイッチを押して、オン(青)にします。

    Edge の場合は、画面の左側のメニューにある「開発者モード」です。

  5. 「パッケージ化されていない拡張機能を読み込む」を押す

    デベロッパー モードをオンにすると、画面の左上に、このボタンが現れます。押してください。Edge の場合は、「展開して読み込み」というボタンです。

    フォルダを選ぶ画面が開くので、手順2で置いたフォルダを選んで、「フォルダーの選択」を押します。手順2の最後に確認した、ファイルが直接並んでいるフォルダを選んでください。

  6. ピン留めして完成

    一覧に「クリアブラウズ」が表示され、スイッチがオン(青)になっていれば、追加できています。

    ブラウザの右上にある、パズルの形のボタンを押して、クリアブラウズの横のピンのマークを押すと、ツールバーにアイコンが出ます。

    広告のあるサイトを開いて、試してみてください。

うまくいかないとき

「マニフェスト ファイルが見つからないか、読み取れません」と出る選んだフォルダの場所が、ずれています。manifest のファイルが直接入っているフォルダを選び直してください。フォルダの中に、もう一つ同じ名前のフォルダがあるときは、その中のフォルダです。
「パッケージ化されていない拡張機能を読み込む」が見当たらない「デベロッパー モード」がオフです。手順4を確認してください。
ブラウザを起動したときに、デベロッパー モードの拡張機能に関する警告が出るストアを通さずに追加した拡張機能では、表示されることがあります。画面を閉じてください。「無効にする」を押すと、拡張機能が止まります。ストアで公開されたあとは、ストア版に入れ替えると出なくなります。
追加したのに、アイコンが見当たらない手順6のピン留めをしてください。
広告が消えない広告のあるページを、再読み込みしてください。それでも残るときは、サポートページの方法で、お知らせください。
拡張機能の欄に、赤い「エラー」ボタンが出ている押すと、エラーの内容が見られます。画面を撮影して、サポートページの方法で、お知らせください。

新しい版に更新する

  1. 新しい zip をダウンロードして、展開する

    手順1と2と同じです。

  2. 古いフォルダの中身を、新しいファイルで置き換える

    同じ名前のファイルは、上書きしてください。

  3. 管理画面で「更新」を押す

    管理画面で、クリアブラウズの欄にある、丸い矢印のボタンを押します。そのあと、広告のあるページを再読み込みします。

削除する

管理画面で、クリアブラウズの欄にある「削除」を押します。設定とエラーログも、すべて消えます。そのあとで、展開したフォルダも消して構いません。
