プライバシーポリシー

制定日: 2026年11月27日 / 提供者: ProjectClearBrowse

クリアブラウズ(以下「本拡張機能」)は、閲覧するウェブページの広告やポップアップを止めるための拡張機能です。この文書では、本拡張機能とこのサイトが、どんな情報を扱い、どんな情報を扱わないかを説明します。

1. 収集しない情報

本拡張機能は、次の情報を収集せず、外部にも送信しません。

  • 閲覧履歴、訪問したページの URL、ページの内容
  • 氏名、メールアドレス、アカウント情報などの個人情報
  • 入力したパスワードやフォームの内容
  • 端末や利用状況を識別するための情報(アクセス解析、広告 ID など)

本拡張機能には、外部のサーバーと通信する仕組みがありません。

2. 端末内に保存する情報

次の情報は、お使いのブラウザの中にだけ保存されます。外部には送信されません。

機能の設定設定画面で切り替えた、各機能のオン・オフ。
ブロックを止めたサイトあなたが「ブロックしない」と選んだサイトのドメイン名。
手動で消した広告あなたが「広告を選んで消す」で選んだ広告の、サイトのドメイン名と位置を表す情報。
エラーログ拡張機能の動作中に起きたエラーの、時刻・発生した処理・エラーメッセージ(最大50件)。閲覧したページのアドレスは含みません。
止めた数の集計タブごとの、止めたポップアップ等の数。ブラウザを閉じると消えます。

これらは、設定画面から消せます。拡張機能を削除すると、すべて消えます。

3. 求める権限と、その目的

すべてのサイトのデータの読み取りと変更すべてのページで広告を見つけて隠すために、ページ上でスクリプトを実行します。読み取った内容は、広告の判定のためだけに端末内で使い、保存も送信もしません。
通信のブロック(declarativeNetRequest)広告会社への通信を、読み込む前に止めるために使います。
ストレージ(storage)上の「端末内に保存する情報」を保存するために使います。

4. 第三者への提供

本拡張機能は情報を収集しないため、第三者への提供、販売、転送はありません。広告やマーケティングなど、本拡張機能の機能と無関係な目的で情報を使うこともありません。

5. お問い合わせ・不具合報告

設定画面の「不具合を報告」は、報告文を端末内で作ります。報告文は、あなたがコピーして送る、またはメールや報告ページを開いて送信するまで、外には出ません。送信前に、プレビューで内容を確認できます。

お問い合わせや不具合報告をいただいた場合、その内容は対応の目的にのみ使い、対応が完了した後は、必要以上に保管しません。

このサイトについて

このサイトは、アクセス解析、Cookie、広告、外部のフォントや外部スクリプトを使っていません。ただし、サイトを配信するサービスが、仕組み上、通信の記録(アクセスログ)を取る場合があります。

ポリシーの変更

この文書を変更する場合は、このページで公開し、制定日を更新します。収集する情報の範囲を広げる場合は、拡張機能の更新情報でも告知します。
