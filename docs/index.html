広告・ポップアップを
ブロックする拡張機能

クリアブラウズは、ポップアップや画面に固定された広告、クリックの乗っ取りなどをブロックする、無料のブラウザ拡張機能です。閲覧履歴やページの内容は収集いたしません。また、当拡張機能が広告を表示することもございません。

ダウンロード(zip・v2.0.0) インストール手順 機能を見る

無料でご利用いただけます。パソコン版の Chrome・Edge・Brave などに対応しております。

※ YouTube など、広告をブロックできないサイトもございます。詳しくはこちらをご覧ください。

現在、Chrome ウェブストアでの公開に向けて準備を進めております。公開までの間は、zip ファイルをダウンロードして、手動で追加していただけます(所要時間は約3分です)。

ブロックできるもの

閲覧中のページ上に表示される、次のようなものをブロックいたします。

ポップアップ・自動で開く新規タブ
クリックしていないにもかかわらず開いてしまう、別のウィンドウや別のタブをブロックいたします。
クリックの乗っ取り
画面全体を覆う透明な板を取り除き、意図しない広告ページへ移動してしまうことを防ぎます。
画面に固定された広告
画面の隅などに固定されたまま動かない、外部サイトの広告を非表示にいたします。
ページ内のバナー広告
一般的な広告サイズのバナー枠を、非表示にいたします。
広告会社への通信
代表的な広告配信ドメインへの通信を、読み込まれる前に遮断いたします。

ブロックされずに残った広告は、手動で消すこともできます。ツールバーのアイコンから「広告を選んで消す」を押し、消したい広告をクリックしてください。以降、そのサイトでは自動的に非表示となります。

ブロックできない場合について

YouTube など、動画の中に広告が組み込まれているサイトでは、広告をブロックできない場合がございます。また、広告ブロックへの対策を行っているサイトでは、広告が表示されたり、ページが正しく表示されなかったりすることがございます。あらかじめご了承くださいますようお願いいたします。

安心してお使いいただくために

当拡張機能は、すべてのサイトのページを扱うため、お客様の情報の取り扱いについて、以下のとおり定めております。

情報を収集いたしません

閲覧履歴、ページの内容、個人情報などを収集せず、外部へ送信することもございません。当拡張機能には、外部のサーバーと通信する機能が備わっておりません。

広告を表示いたしません

収益を目的とした広告の表示、アフィリエイトリンクの挿入、検索結果の差し替えなどは、一切行っておりません。

内容をご確認いただけます

配布しているファイルのプログラムは、圧縮や難読化をしておらず、どなたでもご覧いただけます。ソースコードはこちらです。

必要とする権限と、その理由

インストールの際に、「すべてのサイトのデータの読み取りと変更」という確認が表示されます。広告を検出して非表示にするために、必要となる権限でございます。

すべてのサイトのデータの読み取りと変更すべてのページで広告を検出して非表示にするため、ページ上でプログラムを動作させる必要がございます。読み取った内容が、お使いの端末の外へ送信されることはございません。
通信のブロック広告会社への通信を、読み込まれる前に遮断するために使用いたします。
ストレージ設定、サイトごとのオン・オフ、手動で消した広告、エラーログを、お使いの端末内に保存するために使用いたします。

詳細は、プライバシーポリシーをご覧ください。

ご利用の流れ

インストール後は、特別な設定をしなくても、そのままお使いいただけます。

  1. 拡張機能を追加しますzip ファイルをダウンロードしたうえで、インストール手順のページに沿って追加してください。操作するボタンの名前を、1つずつ記載しております。
  2. アイコンをピン留めしますブラウザ右上のパズルの形のボタンを押し、クリアブラウズの横にあるピンのマークを押すと、ツールバーにアイコンが表示されます。
  3. 広告のあるサイトを開きます広告は自動的にブロックされます。残った広告は、アイコンの「広告を選んで消す」から、手動で消すことができます。

よくある質問

本当に無料でしょうか。

はい、すべての機能を無料でご利用いただけます。寄付は任意であり、寄付の有無によって機能が変わることはございません。

広告が消えないサイトがございます。

YouTube など、動画の中に広告が組み込まれているサイトでは、広告をブロックできない場合がございます。また、広告ブロックへの対策を行っているサイトでも、広告が残ることがございます。

ブロックされずに残った広告は、アイコンの「広告を選んで消す」から、手動で消せる場合がございます。ただし、動画の中に組み込まれた広告は、手動でも消すことができません。それでも広告が残る場合は、設定画面の「不具合を報告」から報告文を作成し、サポートページに記載の方法でお知らせください。

ページの表示が崩れる、ログイン画面が開かない場合は、どうすればよいでしょうか。

アイコンを押し、該当のサイトのみ「ブロックする」をオフにしてください。ログイン用の小さなウィンドウが開かない場合は、設定画面で「ポップアップ・新規タブ」の項目をオフにしていただくこともできます。

どのようなサイトで使えますか。

http または https で開くほとんどのサイトで動作いたします。どのサイトをご利用の場合でも、閲覧履歴やページの内容を収集することはございません。

広告収入で運営しているサイトへの影響は、ございますか。

広告収入によって運営されているサイトもございます。応援したいサイトでは、アイコンから、そのサイトのみブロックを停止していただけます。

スマートフォンや Firefox では使えますか。

現在は、パソコン版の Chrome・Edge・Brave などに対応しております。スマートフォン版の Chrome は、拡張機能に対応していないため、ご利用いただけません。Firefox 版は、現時点では提供しておりません。
