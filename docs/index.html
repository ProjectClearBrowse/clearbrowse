広告を止めて、
静かに見る。

クリアブラウズは、ポップアップ・固定された広告・クリックの乗っ取りを止める、無料のブラウザ拡張機能です。閲覧データは集めません。広告も出しません。

手動でインストールするストア公開準備中 何を止めるか見る

無料 / Chrome・Edge・Brave などの Chromium 系ブラウザ(パソコン)に対応

止めるもの

見ているページの上で動く、うるさい仕掛けを取り除きます。

ポップアップ・勝手に開く新規タブ
クリックしていないのに開く別ウィンドウや別タブを止めます。
クリックの乗っ取り
画面全体を覆う透明な板を取り除き、押したつもりのない広告へ飛ばされるのを防ぎます。
画面に固定された広告
画面の隅に張り付いて動かない、外部サイトの広告を消します。
ページ内のバナー広告
標準的な広告サイズのバナー枠を隠します。
広告会社への通信
代表的な広告配信ドメインへの通信を、読み込みの前に遮断します。

消えない広告は、自分で選んで消せます。アイコンから「広告を選んで消す」を押し、消したい広告をクリックするだけです。そのサイトでは、次から自動で消えます。

3つの約束

全サイトのページを扱う拡張機能だからこそ、何をしないかをはっきり決めています。

データを集めない

閲覧履歴、ページの内容、個人情報を収集せず、外部に送信しません。この拡張機能には、外部サーバーと通信する仕組みがありません。

広告を出さない

収益のための広告、アフィリエイトリンク、検索結果の差し替えは一切入れません。

中身を確かめられる

配布ファイルのコードは圧縮も難読化もしていません。誰でも読んで確かめられます。ソースコードを見る

求める権限と、その理由

インストール時に「すべてのサイトのデータの読み取りと変更」と表示されます。広告を見つけて隠すために、必要な権限です。

すべてのサイトのデータの読み取りと変更すべてのページで広告を見つけて隠すため、ページ上でスクリプトを動かします。読み取った内容は、端末の外へ出ません。
通信のブロック広告会社への通信を、読み込む前に止めるために使います。
ストレージ設定、サイトごとのオン・オフ、手動で消した広告、エラーログを、この端末に保存するために使います。

くわしくはプライバシーポリシーをご覧ください。

使い始める

インストールして、そのまま使えます。設定は要りません。

  1. 拡張機能を追加するストア公開までは、手動インストールの手順をご覧ください。
  2. アイコンをピン留めするブラウザ右上のパズルの形のボタンを開き、クリアブラウズのピンを押すと、いつでも押せる場所に出ます。
  3. 広告のあるサイトを開く広告は自動で止まります。残った広告は、アイコンから「広告を選んで消す」で消せます。

よくある質問

本当に無料ですか?

はい。すべての機能が無料です。寄付は任意で、寄付の有無で機能は変わりません。

広告が消えないサイトがあります

アイコンから「広告を選んで消す」を使うと、そのサイトの広告を自分で選んで消せます。それでも消えないときは、設定画面の「不具合を報告」から報告文を作って、サポートページの方法でお知らせください。

ページが崩れる・ログイン画面が開かないときは?

アイコンを押して、そのサイトだけ「ブロックする」をオフにしてください。ログイン用の小窓が開かない場合は、設定画面で「ポップアップ・新規タブ」の項目を切ることもできます。

どんなサイトで使えますか?

http または https で開くほとんどのサイトで動作します。どのサイトでも、閲覧履歴やページの内容は収集しません。

広告収入で運営しているサイトへの影響は?

広告収入で運営しているサイトもあります。応援したいサイトでは、アイコンからそのサイトだけブロックを止められます。

スマホや Firefox で使えますか?

現在は、パソコン版の Chrome・Edge・Brave などに対応しています。スマホ版 Chrome は拡張機能に対応していないため、使えません。Firefox 版は今のところありません。
