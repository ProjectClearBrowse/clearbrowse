# クリアブラウズ

クリアブラウズは、広告・ポップアップ・クリックの乗っ取りを止める、無料のブラウザ拡張機能です(Chrome / Edge / Brave、パソコン版)。

閲覧履歴やページの内容は収集せず、外部にも送信いたしません。


公式サイト: https://projectclearbrowse.github.io/clearbrowse/


## ブロックできるもの

- ポップアップ、および自動で開く新規タブ
- 画面全体を覆う透明な板による、クリックの乗っ取り
- 画面の隅などに固定された広告
- ページ内のバナー広告
- 広告会社への通信

設定画面で、ブロックの強さを「標準」(おすすめ)と「強力」から選べます。広告が特に多いと判断したページでは、標準の設定でも、自動的に強力で動作いたします。

ブロックされずに残った広告は、アイコンの「広告を選んで消す」から、手動で消すこともできます。

## ご注意

YouTube など、動画の中に広告が組み込まれているサイトでは、広告をブロックできない場合がございます。また、広告ブロックへの対策を行っているサイトでは、広告が表示されたり、ページが正しく表示されなかったりすることがございます。あらかじめご了承ください。

## インストール方法



現在、ストアでの公開に向けて準備を進めております。公開までの間は、次の方法で手動でインストールしていただけます。



[インストール手順のページ](https://projectclearbrowse.github.io/clearbrowse/install.html)に、操作するボタンの名前を1つずつ記載しております。zip ファイルは、[こちらから直接ダウンロード](https://projectclearbrowse.github.io/clearbrowse/download/clearbrowse-extension.zip)していただけます。


このリポジトリのファイルから追加する場合は、次の手順で行ってください。

1. このページの緑色の「Code」ボタンから「Download ZIP」を選び、zip ファイルを保存して展開します(展開したフォルダは、削除しないでください)。
2. ブラウザで `chrome://extensions` を開きます(Edge の場合は `edge://extensions`)。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダの中の `ext` フォルダを選びます。

## 不具合のご報告

[Issues](https://github.com/ProjectClearBrowse/clearbrowse/issues) よりご報告ください。拡張機能の設定画面にある「不具合を報告」から、診断情報を含めた報告文を作成することもできます(閲覧履歴は含まれません)。

## フォルダ構成

| 場所 | 内容 |
|---|---|
| `ext/` | 拡張機能の本体(圧縮・難読化はしておりません) |
| `docs/` | 公式サイト(GitHub Pages で公開しております) |

## 第三者のフィルター

`ext/filters/` のファイルは、EasyList、EasyPrivacy、Fanboy's Annoyance List(https://easylist.to/)を、ブラウザの形式に変換したものです。これらは、元のフィルターのライセンス(GPL v3 以降 / CC BY-SA 3.0 / CC BY 3.0)に従います。詳細は `ext/THIRD_PARTY_NOTICES.txt` をご覧ください。
