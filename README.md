# クリアブラウズ

広告・ポップアップ・クリックの乗っ取りを止める、無料のブラウザ拡張機能です(Chrome / Edge / Brave、パソコン版)。

**閲覧履歴やページの内容は収集せず、外部にも送信しません。** 広告も出しません。


公式サイト: https://projectclearbrowse.github.io/clearbrowse/


## 止めるもの

- ポップアップと、勝手に開く新規タブ
- 画面全体を覆う透明な板による、クリックの乗っ取り
- 画面の隅に固定された広告
- ページ内のバナー広告
- 広告会社への通信

消えない広告は、アイコンの「広告を選んで消す」から、自分で選んで消せます。

## インストール



現在、ストアでの公開を準備中です。それまでは、次の手順で手動インストールできます。


1. このページの緑の「Code」ボタン →「Download ZIP」で、zip を保存します。
2. zip を解凍します(解凍したフォルダは、削除しないでください)。
3. ブラウザで `chrome://extensions` を開きます(Edge は `edge://extensions`)。
4. 右上の「デベロッパー モード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押し、解凍したフォルダの中の **`ext` フォルダ**を選びます。

## 不具合の報告

[Issues](https://github.com/ProjectClearBrowse/clearbrowse/issues) から報告できます。設定画面の「不具合を報告」で、診断情報つきの報告文を作れます(閲覧履歴は含まれません)。

## フォルダ構成

| 場所 | 内容 |
|---|---|
| `ext/` | 拡張機能の本体(圧縮・難読化はしていません) |
| `docs/` | 公式サイト(GitHub Pages で公開) |
